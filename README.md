# theme.the98 has moved

The98 is now maintained in [kkgams/theme.gams](https://github.com/kkgams/theme.gams),
the kkgams GAMS theme collection. Use that repository for source, documentation,
issues and future releases. This repository no longer builds or publishes themes.

The CSS entry remains `themes/the98.css`. After the new collection release is
published, update Project URLs from `theme.the98-<version>.zip#themes/the98.css`
to `theme.gams-<version>.zip#themes/the98.css` under the new repository's releases.
Existing tags, release assets and pinned URLs remain unchanged; do not update
consumers to an unpublished release.

GAMS still supports arbitrary local or external CSS through `ui.theme.url`.
LICENSE and NOTICE are retained for the historical code and releases.
